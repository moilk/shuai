# Android

Not started. The planned Android app uses Jetpack Compose on top of the same Rust core: Kotlin
bindings generated by UniFFI from `core/shuai-ffi`, and libghostty-vt with a Compose renderer for the
terminal. See [ADR 0002](../docs/adr/0002-rust-core-uniffi.md), [ADR 0001](../docs/adr/0001-terminal-engine.md)
and the [roadmap](../docs/roadmap.md).

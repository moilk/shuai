# M0 — bootstrap

Goal: repository, conventions and a toolchain that proves Rust -> UniFFI -> Swift end to end.

Tasks
1. git repo, MIT LICENSE, README, CLAUDE.md, .gitignore.
2. Cargo workspace `core/` (edition 2024, resolver 3) with skeleton crates; `shuai-proto` version/PROTOCOL_VERSION, `shuai-ffi` `ping()`/`core_version()`, `shuai-agent --version`, `uniffi-bindgen` binary.
3. `scripts/build-xcframework.sh`: ios, ios-sim, macos slices + Swift bindings.
4. `apple/ShuaiKit` Swift package with `ShuaiCore` facade and Swift Testing tests.
5. `apple/App` XcodeGen iPad app + unit test calling the Rust core.
6. Placeholders: plugin/, android/, docs/adr, docs/plan.
7. CI: rust, apple, agent-build.

Acceptance: `cargo test`, `swift test`, `xcodebuild test` (iPad simulator) green and pushed to GitHub.
